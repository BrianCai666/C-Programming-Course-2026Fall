# Week-03 课堂练习
## 题目列表

### 题目A
题目描述
输入两个整数a和b，依次输出这两个数的四则运算结果，即a-b,a+b,a*b,a/b

输入
两个整数a和b

输出
依次输出这两个数的四则运算结果

a-b

a+b

a*b

a/b

IO模式
本题IO模式为标准输入/输出(Standard IO)，你需要从标准输入流中读入数据，并将答案输出至标准输出流中。
