### 题目B
题目描述
输入整数，判定该整数是否是水仙花数。

水仙花数是一个三位正整数，数字本身等于其各位立方之和。例如：153 ＝ 1^3+ 5^3＋3^3。

输入
一个整数

输出
1表示该数字是水仙花数

0表示该数字是三正整数，但非水仙花数

ERROR表示该数字非三位数。

IO模式
本题IO模式为标准输入/输出(Standard IO)，你需要从标准输入流中读入数据，并将答案输出至标准输出流中。

### 题目C
题目描述
