### 题目B
题目描述
小三非常迷信数字3，对日期也非常讲究。日期包含年月日三部分，格式为YYYY-MM-DD，如果年对月取模为3，且月对日取模为3，则该日子是幸运日，小三一定去买彩票。

例如日期2012--07--04，得到YYYY是2012，MM是07，DD是04，按数值计算：2012 mod 7 = 3 且 7 mod 4 =3，那么该日期符合幸运日条件

注意日期长度是不可变的，年份长度是必定4位，月和日的长度都是必定2位。例如2012-07-04不能写成2012-7-4，如果年份是980，必须写成0980

输入
第一行输入T表示有T个测试实例

第二行起输入一个日期，按照YYYY-MM-DD的格式

以此类推输入下一个日期

假定输入的日期都是合法的，无须考虑日期合法性检查

输出
如果是幸运日，输出YES，否则输出NO

IO模式
本题IO模式为标准输入/输出(Standard IO)，你需要从标准输入流中读入数据，并将答案输出至标准输出流中。
