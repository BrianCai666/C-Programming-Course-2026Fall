### 题目A
题目描述
输入数字范围n,m（n>=0, m>=0, n<=m)，输出[n,m]区间中的所有素数和。

输入
测试次数T

每组测试数据一行，数字范围n m

输出
对每组测试数据，如果有素数，输出二行：

第一行：输出[n,m]间的素数

第二行：输出[n,m]间的素数和

如果没有素数，输出NO

IO模式
本题IO模式为标准输入/输出(Standard IO)，你需要从标准输入流中读入数据，并将答案输出至标准输出流中。
